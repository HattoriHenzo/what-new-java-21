# What’s New in Java 21

This project is a small Java 21 sample repository demonstrating several new language and API features introduced in Java 21.

## Included examples

- String Templates
- Pattern Matching for `switch`
- Record Patterns
- Virtual Threads

## Requirements

- Java 21 JDK
- Maven

## Run the project

```bash
mvn compile
java --enable-preview -cp target/classes com.esombugma.java.VirtualThreads
```

## Purpose

The goal of this project is to provide a minimal, easy-to-follow reference for exploring Java 21 features in practice.
